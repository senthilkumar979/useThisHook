## useLocalStorage: Use for user preferences that should survive refresh

A preference should survive refresh: theme, sidebar width, last used project. You want useState that writes JSON to localStorage. This is that pair of value and setter, with a fallback if storage is empty or corrupt.

### Install
```bash
npm install usethishook
```

### Example
```tsx
import { useLocalStorage } from 'usethishook';

export const NameField = () => {
  const [name, setName] = useLocalStorage('name', '');
  return <input value={name} onChange={(event) => setName(event.target.value)} />;
};
```

Live demo: https://usethishook.mentorbridge.in/useLocalStorage

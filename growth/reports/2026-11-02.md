### Community draft (review before posting)

## useConfirm: Use before delete or other destructive actions

You need “Are you sure?” before delete, and you want to await the answer in the click handler. Same idea as useOverlay, with a default dialog. Call confirm({ title, danger }), put render() in the tree, branch on true/false.

### Install
```bash
npm install usethishook
```

### Example
```tsx
import { useConfirm } from 'usethishook';

export const Row = () => {
  const { confirm, render } = useConfirm();
  return (
    <>
      <button type="button" onClick={async () => { if (await confirm({ title: 'Delete?' })) remove(); }}>Delete</button>
      {render()}
    </>
  );
};
```
